# TinyTimer

A stopwatch and countdown timer that lives in the MacBook notch. This glossary fixes the words for a countdown and the ways finished countdowns are grouped.

## Language

**Countdown**:
The timer mode that runs from a chosen number of minutes down to zero.
_Avoid_: Timer, Pomodoro

**Session**:
One countdown that reached zero. It records the length it ran for.
_Avoid_: Iteration, item, Pomodoro

**Dot**:
The mark shown for one session.

**Block**:
A stretch of work within one day, made of the sessions finished while it was current. There is always a current block; it ends when another one starts. A block started from a preset takes the preset's name, otherwise it is unnamed and known by its start time.
_Avoid_: Group of sessions, work, period, routine, set

**Preset**:
A saved name and countdown length from which blocks are started. Optional: the timer works without any.
_Avoid_: Template, routine, profile
